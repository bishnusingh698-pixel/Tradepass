## Back-translation check

Kept Taiwan usage from the existing strings (核准, 型錄, 匯入, 證明文件) rather than mainland terms; the back-translation pass checked for mainland terms (页面, 文件 for file, 信息) and uses 網頁, 檔案, 資訊 instead. Plan names include 方案, so common.availableOn became "適用於{plan}" to avoid "方案方案". Block name 批發申請表單 matches the theme schema.
