## Back-translation check

Existing strings used 等级 and 转售证明, so the glossary follows them; certificates in general are 证书. Plan names include 套餐 ("Starter 套餐"), so common.availableOn became "{plan}可用" and Flow/storefront plan messages no longer add 套餐 after {plan}. Theme is 模板 per Shopify Simplified Chinese admin, and the block name 批发申请表单 matches the theme schema.
